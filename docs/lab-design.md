# MV-01 移动实验车：设计说明

把 coding agent 一次任务当成一次实验流程，画成一辆剖开的高顶厢式车改装的实验室。画风参考两份资料：

- [anatomy](https://github.com/wheresryan22/anatomy)：等轴测、纸面四档明暗、0.6px 墨线、一个零件压一个零件的密度、卡片四角（Fig / 标题 / 提示 / 读数），颜色只给"主角"。
- [Every Joule](https://iamtechartist.github.io/every-joule-lesson1/)：纸上的 3D 墨线图、玻璃容器里发光的彩色液体、柔和投影、衬线排版。

## 画面

- 正交相机（等轴测），默认从车尾右侧上方看。近侧车壁和车顶是"半透视"幽灵壳：淡白薄纱 + 细墨线，「透视」滑块从全剖开调到接近整车。车顶两侧的纵梁保持实体，机械臂的导轨吊在车顶中线。
- 车停在展示底板上：圆角板、四脚、槽线、刻度尺、铭牌、角螺丝。
- 渲染：纸面材质按朝向分四档明暗 + 顶面最亮 + 柔和阴影；轮廓线由后处理从法线 / 深度 / 零件 ID 求出；玻璃用菲涅尔描边；液体和指示灯是唯一的饱和色。
- 车长 6 m、宽 2.16 m、顶高 2.36 m，地板面 y=52，台面 y=122。实验区 x −296..172，驾驶室在隔断（x=176）前面。

## 两个数据源

- **全事件演示**：`tools/make_demo_trace.py` 按 grok-build 源码里的结构体构造的一场 8 段会话（计划模式、工具全家桶、子 agent 与工作流、目标模式、压缩与记忆、定时与回退、故障演练、断线收工），覆盖下面图鉴里的全部 131 种事件。所有值都是编的，不来自真实会话。
- **本机回放**：`tools/extract_grok_trace.py` 从 `~/.grok/sessions` 抽取的真实会话，本机只出现过约 17 种事件。

右侧「图鉴」按 L1–L5 列出 131 种事件，出现过的点亮并计数；点一个事件会定位到对应仪器。

## 事件 → 实验流程

| agent 事件 | 车里的仪器 | 动画 |
|---|---|---|
| agent 本身 | 车顶中线导轨上的机械臂 | 取工单、送仪器、倒液、放样；任务积压时加速 |
| 用户消息、插话 | 驾驶台电传打印机、隔断传递窗、对讲机 | 打出委托单，金色样品瓶从传递窗进来；插话时对讲机响 |
| 上下文 `_meta.totalTokens` | 储液塔（对数刻度，85% 红环） | 液位 = 上下文占比 |
| 缓存命中 `response_started.cache_read_input_tokens` | 溶剂回收罐 | 液位 = 命中率，青色管路回流到泵 |
| 模型请求 `loop_started` | 蠕动泵 | 把上下文送进反应釜 |
| 推理 / 正文 / 首 token | 反应釜（三口烧瓶 + 加热套 + 回流冷凝管 + 蒸馏支管） | 紫色回流、蓝色馏出、第一滴 = TTFT |
| 工具调用 / 参数流 | 反应釜侧口 | 橙色工单瓶析出，参数流进来时液位上涨 |
| 读文件 / 列目录 | 显微镜、载玻片转盘 | 底灯、物镜、转盘；屏幕上是路径和内容 |
| 搜索 / grep | 分光仪 | 光谱屏上一条谱线一处命中 |
| 写文件 / 编辑 / diff 审阅 | 移液工作站 + 96 孔板 | 绿孔新增行、红孔删除行 |
| 执行命令 | 通风橱 | 视窗降下、本生灯点火、屏幕滚输出、退出码灯 |
| 联网搜索 / 抓网页、中继同步 | 车顶天线 + 侧门接收机 | 天线转向、接收机出波形 |
| MCP 全套诊断（配置、启动、失败、鉴权、调用、传输错误、重连、健康检查、开关） | 仪器机柜 | 模块自检灯、红灯、火花、心跳 |
| 权限请求、YOLO | 安全联锁（钥匙 + 红绿灯）、模式面板的 YOLO 钥匙 | 人工审批时弹授权单；YOLO 打开后联锁显示 BYPASS |
| 计划模式、批准方案 | 模式旋钮 | 计划模式下反应釜只预热；退出要你批准方案 |
| 待办 `todo_write` / `plan` | 实验记录夹 | 方案逐条打勾 |
| 工具结果回灌 | 墙上的气动传输管 | 结果装进胶囊送回储液塔；失败的由机械臂扔进废液桶 |
| 后台任务、monitor | 恒温摇床 + 墙上记录仪 | 摇床在摇，每行输出记录仪走一笔 |
| 子 agent | 无人机坞站 | 起飞出车、进度闪灯、带结果回来 |
| 工作流 `workflow_updated` | 平行反应阵列 | 一个子 agent 一根反应管，阶段灯 |
| 目标模式 `goal_updated` + 全部 `goal_*` | 目标白板、复核台 | 交付物打勾、预算条；三个怀疑者亮灯给结论 |
| 收尾闸门（待办闸门、偷懒判定、过早收工） | 复核台闸门灯、隔断顶上的监督摄像头 | 摄像头转过来亮红灯，把机械臂推回去 |
| 压缩全套（开始、完成、失败、取消、续跑） | 旋转蒸发仪 | 储液塔抽进旋蒸瓶、旋转、浓缩液送回，液位骤降 |
| 压缩检查点 | 检查点安瓿架 | 每次压缩封一支 |
| 记忆（写入、会话保存、整合、文件） | 液氮罐 | 开盖放冻存管、冒白汽 |
| 回退 `rewind_marker` | 冰柜上方的磁带机 | 倒带，储液塔液位回落 |
| 定时任务 | 24 小时定时器 | 插销、到点铃响、拔销 |
| 重试、doom-loop、自救 | 反应釜 + 警示灯 | 冒烟、颜色振荡、氮气淬灭、警示灯转红 |
| 换模型 | 反应釜控制器 | 屏幕换模型名 |
| 14 种 hook、hook 批注 / 变更、插件 | 质检灯板 | 每种 hook 一盏灯，机械臂扫描头同时扫一下 |
| 会话开始 / 结束 | 总电源 | 合闸、车顶灯带亮；拉闸、熄灭 |
| 标题、回顾、反馈 | 车头路牌、电传打印机 | 路牌换标题；回顾打在纸带上 |
| 回合完成、用量 | 低温样品冰柜、墙上流量计 | 产物封瓶入库（只有真实回放计入长期累计）；四个计数鼓累加 |
| 图片压缩 / 丢弃 | 显微镜 | 屏幕列出压缩前后大小 |
