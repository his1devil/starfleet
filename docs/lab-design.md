# MV-01 移动实验车：设计说明

把 coding agent 一次任务当成一次实验流程，画成一辆面包车改装的移动实验室。画风参考两份资料：

- [anatomy](https://github.com/wheresryan22/anatomy)：等轴测、纸面四档明暗、0.6px 墨线、一个零件压一个零件的密度、卡片四角（Fig / 标题 / 提示 / 读数），颜色只给“主角”。
- [Every Joule](https://iamtechartist.github.io/every-joule-lesson1/)：纸上的 3D 墨线图、玻璃容器里发光的彩色能量、柔和投影、衬线排版、手写批注。

## 画面

- 正交相机（等轴测），默认从车的左前上方看。近侧车壁和车顶做成“半透视”幽灵壳：淡白薄纱 + 细墨线，滑块可以调到全实体或全剖开。车顶骨架（横梁、立柱）保持实体，龙门机器人吊在横梁上。
- 车停在一块展示底板上：圆角板、四脚、槽线、刻度尺、铭牌、角螺丝，和 anatomy 的底板一样。
- 渲染：纸面材质按朝向分四档明暗 + 顶面最亮 + 柔和阴影；轮廓线用后处理从法线 / 深度 / 零件 ID 求出，主体墨色重、结构中、底座浅；玻璃用菲涅尔描边，液体是唯一的饱和色。

## 事件 → 实验流程

| agent 事件 | 实验车里 | 动画 |
|---|---|---|
| agent 本身 | 车顶龙门机器人（X/Z 轨 + 伸缩 Z 轴 + 夹爪） | 移到当前事件的仪器，取放样品瓶；LED 环表示状态 |
| 模型 | 反应釜：三口圆底烧瓶 + 加热套 + 回流冷凝管 + 蒸馏支管 | — |
| 用户消息 `user.message` | 驾驶台上的电传打印机 | 打出纸带（委托单），金色样品瓶 |
| 上下文 `_meta.totalTokens` | 刻度储液塔（0–100%，85% 红线） | 液位 = 上下文占比 |
| 模型请求 `loop.start` | 蠕动泵把储液塔的液体送进反应釜 | 管路脉冲、加热套升温 |
| 首 token `first_token` | 冷凝管滴下第一滴 | TTFT = 加热到首滴的时间 |
| 推理流 `streaming_reasoning` / chunk r | 回流冷凝：紫色蒸汽上升、液滴回落 | 每个 chunk 一滴紫色 |
| 正文流 `streaming_text` / chunk t | 蒸馏支管馏出到接收瓶 | 两通活塞拨向“产物”，蓝色液滴 |
| 工具调用 `tool.call` | 反应釜析出一枚橙色“工单”样品 | 机器人取走送到对应仪器 |
| read / list | 显微镜 | 载玻片、照明、屏幕显示路径 |
| search / grep | 分光仪（光源 → 狭缝 → 棱镜 → 光谱屏） | 命中 = 谱线亮起 |
| write / edit | 移液工作站 + 96 孔板 | 绿孔 = 新增行，红孔 = 删除行 |
| execute（命令） | 通风橱：本生灯、试管、排风扇 | 点火、冒泡、退出码指示灯 |
| ask_user | 驾驶台对讲机 | 机器人拿起听筒，弹出问答 |
| 权限请求 | 通风橱旁的安全联锁（钥匙开关 + 红绿灯） | 机器人停在联锁前等你批准 |
| hook | 龙门上的质检扫描头 | 扫描激光扫过样品 |
| 工具结果 | 绿盖（成功）/ 红盖（失败）样品瓶 | 成功送回储液塔，失败扔进废液桶 |
| 回合完成 `turn.completed` | 产物封瓶贴标，放进后部样品冰箱 | 长期成长线：冰箱逐格装满；里程表 = 累计 token |
| MCP 服务 | 近侧 19 寸仪器机柜 | 模块上电、指示灯自检 |
| 自动压缩（演示） | 旋转蒸发仪 | 储液塔抽到旋蒸瓶，旋转蒸发，浓缩液回流，液位骤降 |
| 子 agent（演示） | 无人机坞站 | 天窗打开，无人机外出取样，按进度闪灯，带回样品 |
| 重试 / doom-loop（演示） | 失控反应 | 反应釜冒黑烟、警示灯旋转；doom-loop = 颜色来回振荡的 BZ 反应 |

## 布局（单位 cm，x 车长、y 向上、z 车宽）

- 车：长 480、宽 190、顶高 205，地板面 y=42，内顶横梁 y≈198，台面 y=112。
- 远侧（z −90..−45，从车尾到隔断）：样品冰箱、通风橱 + 安全联锁、储液塔、反应釜 + 接收瓶、显微镜、分光仪、移液工作站。
- 近侧（低矮，不挡视线）：气瓶架 + 废液桶、旋蒸推车、无人机坞站、MCP 机柜。
- 隔断（x=100）：传递窗、实验记录夹板、挂钟。驾驶室：座椅、方向盘、仪表（速度表 = tok/s，里程表 = 累计 token）、电传打印机、对讲机。
- 车顶：天线、太阳能板、通风橱排风帽、警示灯、无人机天窗。
