# TK-1 推理机：设计说明

MV-01 实验车的姊妹版。画风不变（等轴测、纸面四档明暗、细墨线、密集的小零件，颜色只给"数据"），隐喻从实验流程换成机器本身：一块放大的推理主板。模型、上下文、缓存、工具、权限都画成板上的部件，数据在铜走线上以光脉冲流动，agent 是一辆沿中间通道跑的搬运车。

## 为什么是主板

- 技术架构天然就是框图，框图落到实物上就是一块板：模块是芯片和插卡，箭头是走线，总线宽度、走向、分区都能直接画出来。
- 数据流有了载体：请求、正文、推理、工具参数、回写，各走一条总线，颜色就是数据类型。
- LLM 本身有可画的结构：层 × 位置的 KV 缓存、逐层前向、注意力、采样，都能做成机械动作，而不是一个发光的黑盒。

## 画面

- 600 × 340 的主板放在白色展示底座上，四周是透明机箱，「机箱」滑块调透明度（替代实验车的「透视」）。
- 中间一条通道（LANE A）把板子分成两半：左边是模型侧，右边是工具侧，中间横着一道权限闸门。右边的东西都会碰到外部世界，所以每张工单都要过闸。
- 搬运车是全向轮小车加一条两节机械臂。走远路时臂收起来、车沿通道开；到了地方臂伸出去取放卡匣。镜头默认跟着它。
- 唯一的饱和色是数据：卡匣盒盖、KV 格子、总线上的光脉冲、指示灯。

## 核心：层墙与解码小车

模型画成一面墙：12 层托盘（transformer 的层）× 28 列（上下文里的一段段位置），每个格子是这一段在这一层的 key / value，也就是 KV 缓存。

| 时刻 | 墙上发生什么 |
|---|---|
| 请求开始 `loop_started` | DMA 从卡匣读出全部消息，青色脉冲沿总线送进来 |
| 缓存命中 `response_started` | 命中的前缀列直接亮成青色；剩下的列由解码小车从左到右扫一遍，预填成蓝绿色 |
| 每生成一个 token | 小车停在最新一列，读头从底层爬到顶层（一次前向），每层都拉出几道注意力弧连回前面的列（总包括第 0 列，注意力汇） |
| 采样 | 小车顶上的转盘一圈 16 根 logit 柱，指针挑中一根，亮成 token 的颜色并弹出一粒 |
| 颜色 | 紫色推理（卷到推理卷盘），蓝色正文（沿总线送到终端），琥珀色工具参数（落进派单托盘，攒成工单） |

## 事件 → 板上部件

| agent 事件 | 部件 | 动画 |
|---|---|---|
| agent 本身 | 通道里的搬运车 | 取工单、过闸、插卡、回写；任务积压时加速 |
| 用户消息、插话、提问、反馈 | 左前角的 I/O 终端 + 进件托盘 | 屏幕打出委托；金色卡匣出现在托盘上，由小车插进卡匣槽 |
| 上下文 `_meta.totalTokens` | 上下文卡匣 + 灯柱 | 每条消息一盒卡匣（金 / 蓝 / 绿 / 红 / 青盖），灯柱是对数刻度的占用，85% 红线 |
| 模型请求 `loop_started` | 预填充 DMA | 屏幕显示请求序号，青色脉冲从卡匣流向核心 |
| 推理 / 正文 / 首 token / 工具参数 | 层墙 + 解码小车 + 采样转盘 | 见上一节 |
| 缓存命中 | 层墙前缀 | 青色列 |
| 推理整段 | 推理卷盘 | 紫色脉冲卷上卷盘，越想越厚 |
| 工具调用 | 派单托盘 → 闸门 → 工具模块 | 琥珀卡匣成形，小车取走、过闸、插进模块 |
| 读文件、图片 | 读取器（平板扫描） | 光条扫过玻璃板，屏幕上是路径和内容 |
| 列目录 | 目录索引（卡片转筒） | 转筒翻动 |
| grep / glob | 检索扫描（文件条 + 激光横梁） | 每处命中在文件条上点一个刻点 |
| 写文件 / 编辑 / 改动审阅 | 改动绘图仪 | 笔头逐行画出改动：绿线新增，红线删除 |
| 执行命令 | 沙箱（玻璃容器里的小机器） | 灯闪、风扇转、侧面终端滚动输出、退出码灯，失败冒火花 |
| 联网、中继 | 外网天线 | 抛物面天线转向，调制解调器出波形 |
| MCP 全套 | MCP 背板 | 每个服务一张卡：琥珀启动、绿在线、红故障；线缆接到板外的服务器盒 |
| 权限请求、拒绝、YOLO | 权限闸门 | 光幕扫过、绿灯；等人时栏杆落下、黄灯闪；拒绝红灯、工单进废料盒；YOLO 屏显 BYPASS |
| 计划模式、批准方案 | 模式钥匙 | 旋钮拨到 PLAN，核心低功率运行，闸门显示 PLAN |
| 计划、待办 | 计划屏（电子纸） | 逐条打勾 |
| 工具结果 | 搬运车 | 绿色结果卡匣插回上下文卡匣；失败的扔进废料盒 |
| 后台任务、monitor | 后台协处理器 | 风扇转、计时；每行监视输出在示波屏上走一笔 |
| 子 agent | 子核插座 | 小核心升起飞出机箱，进度灯，飞回落座，小车取回结果 |
| 工作流 | 芯粒阵列 | 一个子 agent 一颗芯粒，阶段灯 |
| 目标模式 + 全部 `goal_*` | 目标板 + 验证夹具 | 交付物打勾、预算条；三根怀疑者探针落下测试、汇总灯 |
| 收尾闸门（待办闸门、偷懒判定、过早收工） | 验证夹具的闸门灯、闸门横梁下的巡检相机 | 相机转过来亮红灯，把小车推回去 |
| 自动压缩全套 | 压缩机 | 卡匣一盒盒飞进压机，压头落下，吐出一盒青色摘要卡匣，小车插回第一格 |
| 压缩检查点 | 快照 | 每次压缩封一块玻璃快照 |
| 记忆（写入、保存、整合、文件） | 记忆盘 | 闪存格子逐格亮起；整合时格子重排 |
| 回退 `rewind_marker` | 日志环 | 指针倒扫回目标回合，后面的格子熄灭 |
| 定时任务 | 实时时钟 | 24 小时表盘插销、到点响铃 |
| 重试、doom-loop、自救、换模型 | 核心 + 信号灯塔 | 读头和注意力弧变红闪烁、冒烟；自救时青光复位；灯塔转红 |
| 14 种 hook、批注、插件 | 通道边的 Hook 总线 | 一种 hook 一盏灯，搬运车扫描头同时扫一下 |
| 会话开始 / 结束 | 电源 | 板边一圈电源轨亮起 / 熄灭 |
| 标题 | 前沿的点阵铭牌 | 换上会话标题 |
| 回合完成、用量 | 归档架、计量表 | 这一轮封成卡匣放上通道尽头的阶梯架；四个计数器累加 |

## 代码

- 共享：`prototype/src/shared/`（纸面材质与墨线后处理、几何零件库、HUD、事件图鉴、时间线）。
- 本版：`prototype/src/engine/`，`30-board` 底座、主板、总线与光脉冲、板上零件、机箱；`40-core` 卡匣、DMA、层墙与解码小车、推理卷盘、压缩机、快照；`45-tools` 闸门与工具侧；`47-parts` 其余部件；`50-courier` 搬运车；`70-director` 事件 → 动画与对话框；`80-main` 相机、输入、主循环。
- `python3 prototype/build.py --variant engine` 输出 `prototype/dist/engine.html`。
